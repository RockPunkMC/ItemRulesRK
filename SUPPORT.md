# Support

Before opening an issue:

1. Read the wiki and troubleshooting page.
2. Run `/itemrules doctor`.
3. Test with the latest official ItemRulesRK release.
4. Confirm that the problem is not caused by an outdated optional dependency.

Include exact server, Minecraft, Java and plugin versions, complete reproduction steps, relevant configuration and the full error stack trace. Remove passwords, tokens, IP addresses and personal player data.

Use Issues for reproducible bugs and documentation problems, not for sharing confidential security reports.
