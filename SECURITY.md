# Security policy

Please do not publish exploitable vulnerabilities, duplication methods or permission bypasses in a public issue before a fix is available.

Report security problems privately to RockPunkMC through GitHub's private vulnerability reporting feature when available. Include the ItemRulesRK version, server software, Minecraft and Java versions, reproduction steps and relevant logs with credentials removed.

Supported security fixes target the latest ItemRulesRK release. Never include server tokens, database passwords, player personal information or private configuration secrets in a report.
